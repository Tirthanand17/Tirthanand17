# Services & Work Requests

I take on small, clearly scoped remote projects in Python automation, data processing, analytics, and document workflows.

## Fixed-scope services

### Excel / CSV Automation
Best for repetitive spreadsheet cleanup, merges, deduplication, normalization, formatting, validation, and export workflows.

Typical starter range: **$25-$120** depending on scope.

### OCR / PDF Processing
Best for searchable PDFs, document conversion, text extraction, batch processing, and repeatable document workflows.

Typical starter range: **$20-$100** depending on file count and complexity.

### Python Automation
Best for scripts that remove repetitive manual work, transform files, validate data, generate reports, or connect simple APIs.

Typical starter range: **$40-$200+** depending on requirements.

### Data Analysis & Reporting
Best for cleaning datasets, exploratory analysis, KPI summaries, dashboard-ready data, and reproducible reports.

Typical starter range: **$50-$250+** depending on scope.

## Delivery principles

- Clear scope before implementation
- Reproducible code and setup
- Validation/testing where practical
- No fabricated data or misleading claims
- Clean handoff with instructions
- Client data kept private
