- **ML rigor:** chronological evaluation, frozen holdouts, explicit MAE/RMSE/R², prospective evidence

- **Software engineering:** APIs, dashboards, CI, tests, configuration separation, documentation
- **Safety/reliability:** dry-run modes, fail-closed gates, secret separation, bounded automation
- **Practical delivery:** reproducible setup instructions and end-to-end runnable project structures
