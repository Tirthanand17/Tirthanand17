## 1. Cricket Score Prediction using Machine Learning

**Repository:** [Tirthanand17/Cricket-Score-Prediction-By-Using-Machine-Learning](https://github.com/Tirthanand17/Cricket-Score-Prediction-By-Using-Machine-Learning)

An end-to-end innings-total forecasting platform covering **T20, ODI, and Test cricket**, with reproducible research, chronological evaluation, API serving, a web frontend, and prospective unseen-match evidence capture.

**Reviewer evidence**
- T20 historical holdout: **MAE 16.74 runs**, RMSE 24.03, R² 0.742
- T20 18-over checkpoint: **MAE 5.75 runs** across 1,067 matches
- ODI and Test format-specific evaluation
- Leakage-safe chronological feature pipelines
- Frozen final holdouts and development/production separation
- Prediction intervals / uncertainty where calibrated
- FastAPI backend + Next.js frontend
- Automated CI and runtime readiness checks
- Checksum-verifiable model artifact workflow
- Immutable prospective prediction journal for future real matches

**Skills:** Python · pandas · scikit-learn · XGBoost · feature engineering · model evaluation · FastAPI · Next.js · testing · reproducibility
