## Decision Rule for Future Projects

Before paying for a developer tool, cloud service, deployment platform, database, domain, course, monitoring product, or coding assistant:

1. Check the current GitHub Student Developer Pack.
2. Prefer a suitable included/free student benefit when it meets the project requirements.
3. Do not activate a time-limited benefit until there is a near-term use.
4. Never add a payment method or accept a paid conversion without explicit approval.
5. Keep production credentials outside GitHub and use environment variables / secret stores.
